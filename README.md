# Deck Presentasi Interaktif — Data Art 2026: Extending Life
### Insight Session: Sustainable Life &bull; Malam Kangen Dies Natalis FMIPA UGM ke-71

Web presentasi interaktif dan naskah presentasi berstandar tinggi untuk **Krisostomus Nova Rahmanto, S.Kom., M.Sc.** dalam rangka mengisi sesi kehormatan **Insight Session: Sustainable Life** pada acara **Malam Kangen FMIPA UGM (Dies Natalis ke-71)**, Sabtu 19 September 2026 di Selasar Gedung D FMIPA UGM.

Presentasi ini difokuskan sebagai **pitching kemitraan strategis, penggalangan dana sponsorship, dan ajakan gotong-royong alumni FMIPA UGM** untuk perhelatan akbar pameran seni-sains **Data Art 2026: Extending Life** di tiga kota (Yogyakarta di GIK UGM, Bandar Lampung di Taman Budaya Lampung, dan Denpasar Bali di Taman Budaya Denpasar).

## 3. Cara Menjalankan

### Opsi A (Paling Cepat & Praktis):
**Klik dua kali berkas `index.html`.**  
Slide langsung berjalan di peramban (Google Chrome, Microsoft Edge, Mozilla Firefox) tanpa perlu instalasi apa pun, tanpa server lokal, dan tanpa koneksi internet.

### Opsi B (Melalui Localhost):
Jalankan berkas `start.cmd` pada terminal, peramban akan otomatis membuka alamat `http://localhost:8080`.

## 4. Pintasan Keyboard Presenter

| Tombol | Fungsi |
|---|---|
| `→` / `Space` / `PageDown` | Slide berikutnya |
| `←` / `PageUp` | Slide sebelumnya |
| `Home` / `End` | Slide pertama / Slide terakhir |
| `N` | **Catatan Presenter (Speaker Notes)** &mdash; Membuka panduan naskah bicara per slide |
| `T` | **Timer 15 Menit** &mdash; Stopwatch pemantau durasi sesi dengan penanda agenda |
| `M` | **Menu Bab** &mdash; Melompat langsung ke bab tertentu |
| `O` | **Overview Thumbnail** &mdash; Tampilan seluruh 17 slide dalam satu layar |
| `F` | **Layar Penuh (Fullscreen)** |
| `?` | Dialog bantuan pintasan |
| `Esc` | Menutup dialog modal yang aktif |

> **Navigasi Mouse:** Klik sepertiga kiri layar untuk mundur, atau klik dua pertiga kanan layar untuk maju. Kontrol tombol interaktif pada widget tetap berfungsi independen.

## 5. Fitur Interaktif Terpasang

1. **Methods Matrix Explorer (Slide 7):** Eksplorasi interaktif bagaimana data riset dari 8 program studi FMIPA UGM (Ilkom, Elins, Matematika, Fisika, Kimia, Statistika, Aktuaria, Geofisika) bertransformasi menjadi karya seni berbasis komputasi murni.
2. **Sponsorship Tier Picker (Slide 14):** Simulator interaktif paket sponsorship resmi: Diamond Partner (Rp 250 Jt), Gold Partner (Rp 150 Jt), Silver Partner (Rp 100 Jt), dan Lab & Artwork Grant (Rp 25–50 Jt) beserta rincian fasilitas dan kontak narahubung.
3. **Timer Insight Session 15 Menit (Tombol T):** Dilengkapi penanda alokasi waktu menit 0 hingga menit 15 agar presentasi selesai tepat waktu sebelum acara musik dan ketoprak dimulai.
